# Цифровой механик

AI-агент для механика автопарка. Он получает результат акустической проверки двигателя от ML-сервиса «НейроДВС», объясняет отклонение и риск, отвечает на вопросы строго по заводскому руководству на двигатель выбранной машины со ссылкой на страницу PDF и по подтверждению механика оформляет заявку на дефектовку в ТОиР.

Хакатон «ИИкузница», трек «Цифровой аватар», 26–28.11.2026.

**Стенд:** https://smartleoai-digital-mechanic.hf.space. Если стенд долго не открывали, первая загрузка занимает 1–2 минуты.

## Запуск за 5 минут

Нужен Python 3.10+.

```bash
python -m venv .venv
.venv\Scripts\activate            # Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
copy .env.example .env            # Linux/macOS: cp .env.example .env
python -m scripts.run_all
```

Откройте http://127.0.0.1:8000. Команда `run_all` поднимает заглушку ML (порт 8001), заглушку ТОиР (порт 8002) и приложение.

Без ключа LLM приложение работает в **демо-режиме**: инструменты те же, но ответы собираются из найденных фрагментов руководства без LLM. Для полноценного агента впишите в `.env` значение `LLM_API_KEY`.

Поисковый индекс по руководствам (`data/index/chunks.jsonl`) уже лежит в репозитории. PDF нужны только для кнопки «Открыть PDF на странице» и для перестроения индекса:

```bash
python -m scripts.fetch_manuals    # скачать 6 PDF с Яндекс Диска заказчика в data/manuals/
python -m scripts.build_index      # перестроить индекс; страницы-сканы распознаются Tesseract (rus+eng), если он установлен
```

Docker: `docker build -t mechanic . && docker run -p 8000:8000 --env-file .env mechanic`. При сборке образ сам скачивает PDF, чтобы на стенде работала кнопка «Открыть PDF».

**Стенд на Hugging Face Spaces (бесплатно).** Блок настроек в начале этого README — конфигурация Space: тип Gradio, точка входа `space_app.py`. Gradio не используется: `space_app.py` поднимает заглушки и приложение на порту 7860 и в фоне скачивает PDF. Бесплатный Space типа Gradio работает на ZeroGPU, поэтому `space_app.py` объявляет пустую функцию `@spaces.GPU` и отправляет платформе отчёт о запуске; GPU приложение не использует. Создайте Space типа Gradio, в Settings → Variables and secrets добавьте секрет `LLM_API_KEY` и отправьте код: `git push https://huggingface.co/spaces/<владелец>/<space> main`. Сервер должен быть вне РФ, потому что Gemini API недоступен с российских IP.

**Стенд на Render** (платный тариф): New → Blueprint, этот репозиторий, затем `LLM_API_KEY` в Environment — `render.yaml` создаст Docker-сервис во Франкфурте.

## Настройки (.env)

| Переменная | Назначение |
|---|---|
| `MOCK_ML_URL`, `MOCK_TOIR_URL` | адреса ML-сервиса и ТОиР; для боевого режима подставьте рабочие URL, код менять не нужно |
| `LLM_PROVIDER` | `gemini` (Google AI Studio, по умолчанию в `.env.example`), `anthropic` (Claude, официальный SDK) или `openai` (любой OpenAI-совместимый endpoint: OpenRouter, YandexGPT, Ollama, vLLM) |
| `LLM_MODEL`, `LLM_API_KEY`, `LLM_BASE_URL` | модель, ключ и адрес API; для Gemini адрес подставляется сам |
| `LLM_EFFORT` | глубина рассуждений: `low`, `medium` (по умолчанию) или `high` |

Проверить ключ и модель: `python -m scripts.check_llm`. Скрипт выведет список доступных моделей и сделает пробный ход агента с вызовом инструмента; перед этим должны быть запущены заглушки.
| `LLM_FALLBACKS` | `1` — если модель откажется отвечать, Anthropic сам перезапросит ответ у другой модели (beta-функция) |

## Как устроено

```
Браузер (телефон)  ──SSE──►  FastAPI app/server.py
                               │
                               ▼
                     Агент app/agent.py — LLM сама выбирает инструменты
       ┌───────────────┬───────────────┬────────────────┬───────────────┐
 get_diagnosis   search_manuals   read_manual_page  get_vehicle_history  prepare_ticket / submit_ticket
       │          (BM25 по руководствам              │                   │
       ▼           только на двигатель ТС)           ▼                   ▼
  Mock ML API                             vehicles.json + история заявок  Mock ТОиР API
```

- **Инструменты разделены** (`app/tools.py`). Сценарий не зашит цепочкой if-else: модель по контексту решает, что вызвать.
- **RAG** (`app/rag.py`, `scripts/build_index.py`). PDF режутся на фрагменты с номером страницы PDF. Поиск — BM25 с русским стеммингом и всегда в пределах руководств на двигатель выбранной машины, поэтому норматив от другого двигателя в выдачу не попадает. 39 страниц без текстового слоя распознаны через OCR.
- **Ссылки проверяемы.** Агент ставит ссылку в формате `[[manual_id:страница]]`. В интерфейсе это кнопка: она открывает текст страницы и PDF на нужном месте. Ссылка на страницу, которую агент не получал поиском, подсвечивается красным. Сервер принимает в заявку только ссылки на страницы, реально найденные в этом диалоге.
- **Проверка чисел** (`app/verify.py`). Каждое значение с единицей измерения в ответе (Н·м, мм, МПа, кгс/см², °C…) сверяется с текстом страниц, которые агент получил в этом диалоге. Значение, которого там нет, показывается механику с предупреждением «Не подтверждено руководством».
- **Устойчивость к перегрузке LLM.** При ответе 503/429 агент повторяет запрос и переходит на резервные модели (`LLM_FALLBACK_MODELS`). На бесплатном тарифе Gemini лимит — около 15 запросов в минуту, а агент делает 2–4 запроса на ответ; для демонстрации жюри нужен платный тариф.
- **Приоритет** (`app/domain.py`) агент предлагает по базовой критичности типа неисправности с поправкой по оценке отклонения и показывает, на чём он основан. Высокий — критичный узел (F02 давление масла, F03 охлаждающая жидкость в масле, F14 цепь ГРМ) или `anomaly_score ≥ 0,80`. Средний — важный узел (F01, F08, F09) или `anomaly_score ≥ 0,65`. Иначе — низкий. Окончательный приоритет механик выбирает в карточке заявки.
- **Качество проверки.** При `bad` выводов и заявки нет. При `warning` всегда показывается предупреждение, и заявка отправляется только после отметки механика. При уверенности ниже **0,50** заявка не оформляется.
- **Противоречия в руководствах.** Агент приводит обе формулировки дословно со страницами и рекомендует уточнить у специалиста. Проверка — контрольный вопрос о тепловых зазорах ЯМЗ-236М2 в `scripts/eval_questions.py`.
- **Проверка применимости.** Если тип неисправности не подходит к двигателю (зажигание у дизеля, ТНВД у бензинового, узел, которого нет в руководствах на этот двигатель), агент предупреждает о вероятной ошибке классификации и заявку не оформляет: так требует ответ организаторов на вопрос 11.
- **Подтверждение заявки.** Агент готовит черновик. Механик видит полный состав заявки и отправляет именно его кнопкой «Отправить в ТОиР». Номера заявок приложение хранит само (`data/state/tickets.json`).

## Сценарии

| Сценарий | Что показать |
|---|---|
| С1. Отклонение → заявка | `M333YK47`, проверка `S-0005` (F08, ЯМЗ-236М2) → вердикт, риск, проверки со ссылками → «Создать заявку» → «Отправить в ТОиР» |
| С2. Вопрос по базе | «Какой момент затяжки болтов крышек коренных подшипников?» на ЯМЗ-236М2 → **421–461 Н·м**, 236.01.01 РК, стр. 41 |
| С3. Сбой записи | `P456AT178`, проверка `S-0003` → заключение о двигателе не формируется, просьба повторить запись |
| Тип не подходит к двигателю | `P854BT78`, проверка `S-0021` (F14 «цепь ГРМ» на ЯМЗ-236М2) → предупреждение, заявка не оформляется |
| С4. Главный механик | вкладка «Парк»: карантин / внимание / норма, график anomaly_score, история проверок и заявок |

## Что использовано (п. 4.8 Положения)

Библиотеки: FastAPI, Uvicorn, Pydantic, httpx, python-dotenv, Anthropic Python SDK, OpenAI Python SDK, PyMuPDF, rank-bm25, snowballstemmer, NumPy, pytest; OCR — Tesseract (rus+eng). Модель — Gemini через Google AI Studio (OpenAI-совместимый API); поддерживаются также Claude (Anthropic API) и любой OpenAI-совместимый API. Заглушки ML и ТОиР, `vehicles.json`, `fault_types.json` и PDF-руководства предоставлены заказчиком (`mock_services/`). Ранее созданных наработок нет. Интерфейс написан на чистом HTML, CSS и JS без сборки.

## Ограничения

- Данные синтетические. Заглушка ТОиР хранит заявки в памяти: после её перезапуска нумерация снова начинается с TKT-0001.
- В демо-режиме без LLM ответ — это найденные фрагменты, а не связный текст.
- Цифры со страниц, распознанных OCR, агент помечает как требующие сверки с бумажным руководством.
