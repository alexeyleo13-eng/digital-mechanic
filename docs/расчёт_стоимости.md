# Расчёт стоимости одного запроса — черновые данные

Это исходные данные для шаблона организатора: самого шаблона в материалах нет. После получения шаблона цифры переносятся в него.

## Что считается запросом

Запрос — одно сообщение механика: «Получить результат диагностики», вопрос по руководству или «Создать заявку».

На один запрос агент делает 2–3 вызова LLM:
1. Модель выбирает инструмент.
2. Модель получает результат инструмента и при необходимости ищет ещё.
3. Модель пишет ответ.

Поиск по руководствам (BM25) и вызовы заглушек ML и ТОиР выполняются локально и в стоимость LLM не входят.

## Замер (26.11.2026, `scripts/eval_questions.py`, данные в `data/state/usage.json`)

| Запрос | Вызовов LLM | Токены на входе | Токены на выходе* |
|---|---|---|---|
| Вопрос по руководству («момент затяжки крышек коренных подшипников») | 2 | 8 352 | 287 |
| Сбой записи (С3) | 2 | 5 629 | 103 |
| Отклонение: диагностика + проверки по руководству (С1) | 3 | 11 254 | 693 |
| Создание заявки (С1) | 2 | 14 461 | 563 |
| **Среднее на запрос** | **2,25** | **≈ 9 900** | **≈ 410** |

\* Gemini тарифицирует токены рассуждений как выходные. В замере на `gemini-3.5-flash-lite` их было мало. Для `gemini-3.8-flash` с `reasoning_effort=medium` в расчёте заложено 800 выходных токенов на запрос.

Входные токены на вызов складываются так: системная инструкция и карточка ТС (≈ 2,5 тыс.), история диалога, найденные фрагменты руководства (6 фрагментов по ≈ 1,4 тыс. символов).

## Стоимость одного запроса

| Модель | Вход | Выход | Итого за запрос | 1 000 запросов |
|---|---|---|---|---|
| gemini-3.8-flash, до 31.12.2026 | 9 900 × 0,75 / 10⁶ = $0,0074 | 800 × 3,75 / 10⁶ = $0,0030 | **≈ $0,010** | ≈ $10 |
| gemini-3.8-flash, с 01.01.2027 | $0,0149 | $0,0060 | **≈ $0,021** | ≈ $21 |
| gemini-3.5-flash-lite | $0,0030 | 410 × 2,50 / 10⁶ = $0,0010 | **≈ $0,004** | ≈ $4 |

**Оценка для парка:** 50 ТС, одна проверка на ТС в неделю, около 5 запросов на проверку → ≈ 1 100 запросов в месяц. Это ≈ $11 в месяц на gemini-3.8-flash (≈ $23 с 2027 года) без учёта хостинга.

**Чем можно снизить стоимость:** неявное кэширование Gemini (системная инструкция повторяется в каждом вызове: кэш $0,075 против $0,75 за 1 млн токенов) и меньшее число фрагментов в выдаче поиска.

**Хостинг стенда:** $0 — бесплатный Hugging Face Space (2 vCPU, 16 ГБ памяти). Для промышленной эксплуатации нужен сервер вне РФ (Gemini API недоступен с российских IP) либо замена модели на доступную в РФ.
