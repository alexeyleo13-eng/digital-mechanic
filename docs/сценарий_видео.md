# Сценарий демонстрационного видео (до 3:00, одним дублем)

Правила организаторов:
- запись одним фрагментом, без вырезания, склейки и эффектов;
- ускорять можно только ожидание ответа модели;
- на видео должны быть три сценария: отклонение → заявка, вопрос по базе знаний, сбой записи.

## Подготовка (до записи)

1. Запустить `python -m scripts.run_all` или открыть стенд. Проверить, что в шапке показана модель, а не «демо без LLM».
2. Открыть страницу на телефоне, либо в браузере в режиме мобильного экрана (DevTools → 390×844).
3. Сделать один пробный прогон. Затем обновить страницу, чтобы чат был пустым.
4. Писать экран со звуком голоса или с субтитрами-подписями в кадре. Подписи должны быть частью интерфейса записи, а не эффектом монтажа.

## Сценарий

| Время | Действие | Что сказать / показать |
|---|---|---|
| 0:00–0:15 | Открыт стенд, вкладка «Механик» | «Цифровой механик: агент объясняет результат акустической проверки НейроДВС и работает строго по заводскому руководству на двигатель этой машины» |
| 0:15–0:25 | Выбрать машину `M333YK47` (МАЗ-5337, ЯМЗ-236М2), в списке проверок выбрать `S-0005` | Карточка ТС, двигатель, график anomaly_score |
| 0:25–1:05 | «Получить результат диагностики» | Шаги агента: запрос в НейроДВС → поиск в руководстве. Карточка: **Отклонение F08, риск средний**, раскрыть «на чём основан приоритет». Ответ: причины, проверки, нормативы — например, давление впрыска форсунок 22,6 МПа и момент затяжки 50–62 Н·м — со ссылками |
| 1:05–1:15 | Нажать ссылку «ЯМЗ-236 РК, стр. 255» | Открывается текст страницы и кнопка PDF: норматив действительно там |
| 1:15–1:45 | Кнопка «Создать заявку на дефектовку» → карточка черновика → «Отправить в ТОиР» | Состав заявки: работы, запчасти, ссылки, приоритет. ✅ «Заявка TKT-000N создана» |
| 1:45–2:15 | Вопрос: «Какой момент затяжки болтов крышек коренных подшипников?» | Ответ **421–461 Н·м**, ЯМЗ-236 РК, стр. 41 — ответ по базе знаний |
| 2:15–2:30 | (по времени) «Можно ли своим ходом перегнать на базу?» | Ответ по руководству или честное «прямых данных нет» |
| 2:30–2:45 | Выбрать машину `P456AT178`, проверка `S-0003` → «Получить результат» | **Сбой проверки**: заключение не формируется, просьба повторить запись |
| 2:45–3:00 | Вкладка «Парк» | Карантин / внимание / норма, клик по машине — история и график |

Запасной сценарий на случай лишнего времени — тип неисправности не подходит к двигателю: `P854BT78`, проверка `S-0021` (цепь ГРМ на ЯМЗ-236М2). Агент предупреждает и заявку не оформляет.

## Риски записи

- **Бесплатный тариф Gemini:** около 15 запросов в минуту, а основные модели бывают перегружены (503). На время записи лучше включить платный тариф в AI Studio. Иначе можно ускорить фрагменты ожидания — это разрешено.
- **Номера заявок:** заглушка ТОиР нумерует заявки с TKT-0001 после каждого перезапуска. Перед записью перезапускать не обязательно.
